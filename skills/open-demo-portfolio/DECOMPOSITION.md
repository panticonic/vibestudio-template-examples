1. A typed planner selects at least one meaningful acceptance criterion in each application. Use the current card when the user refers to it. Preserve the difference between recorded, projected and missing evidence promptly when the card changes.
2. Exact bound services read two checkpoints of the same owned pair and, when appropriate, the requested native forecast. Typed Grimoire and Regency children call the respective installed review subtrees and preserve each finding and evidence ID.
3. A typed decision composes the two claim sequences. A contradicted criterion blocks readiness, missing evidence leaves it incomplete, and a private diagnostic may still be written when explicitly requested. The user may ask for ready-only delivery with no file on a negative outcome.
4. Independent verification checks exact readonly snapshots, settled time and assigned actions, full reviewed call arguments, final interpretation, and any requested local note. No new game mutation or publishing capability is available to the model.

Source verification executes the native Grimoire and Regency engine laws and the existing exact reviewers against file-backed scratch. Managed fixtures use the actual workers with fixed owned inputs and no external service, storyteller, rendered panel, or model.
